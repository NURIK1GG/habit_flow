## Сценарии

- Domain: пустая серия, незавершённый сегодня, пропущенный вчера, дни отдыха, лучшая серия после разрыва.
- Application/SQLite: создание и упражнения; check-in/undo; подсчёт очков и минут; уникальность даты; будущие/слишком старые даты; запрет чужого чтения и изменения; архив и восстановление; фиксация расписания; конфликт Revision; рекурсивная проверка упражнений; закрытые профили; применение миграции.
- State: busy/loaded события, сериализация параллельных обновлений, сохранение последнего snapshot при ошибке, отсутствие загрузки после Dispose, тосты.
- Components: данные карточки и callback, блокировка повторной отметки, диапазон графика и таблица, dismiss тоста, отображение себя в рейтинге, валидация и отправка формы.
- Security/HTTP: защищённый hub, login cookie HttpOnly, запрет Admin обычному пользователю, доступ Admin, antiforgery 400, неверный пароль, проверка security stamp, немедленное обнаружение блокировки сервисом и проверка роли по БД.
- Production: только настроенный bootstrap administrator, отсутствие demo routines, повторный seed без дубликатов.
- E2E: регистрация → программа с упражнением → check-in → журнал → undo → публичность → рейтинг → archive/restore; синхронизация двух сессий; Admin suspension/restore; график, адаптивность, accessibility.
